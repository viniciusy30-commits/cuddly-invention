Importante: o Pokéidle bloqueia a exibição dentro desta página, então cada atalho abre o site oficial diretamente no navegador. Esta página não consegue escolher automaticamente um perfil do Safari nem criar sessões isoladas por código.

Como tentar manter contas separadas no iPhone

  1. No Safari, toque no botão de abas e abra o menu de perfis.
  2. Crie perfis diferentes, por exemplo Conta 1, Conta 2, Conta 3 e Conta 4.
  3. Entre no perfil desejado antes de abrir o atalho correspondente abaixo.
  4. Abra o Pokéidle e entre na conta. Repita o processo dentro de cada perfil.

Os perfis do Safari mantêm dados de navegação separados, mas o iPhone não permite que esta página force cada link a abrir em um perfil específico. A troca de perfil é manual, e a execução simultânea em segundo plano não é garantida.

Use um atalho de cada vez, depois de selecionar o perfil correto no navegador.
