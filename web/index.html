Quad Pokeidle

Quatro atalhos para abrir o jogo separadamente

Por que mudou? O Pokéidle recusou ser carregado dentro dos painéis. Agora cada botão abre o site oficial em uma nova aba, sem iframe. Importante: no iPhone, as abas do Safari normalmente compartilham os cookies; isso não garante quatro contas logadas ao mesmo tempo.

Toque em cada botão para abrir uma aba do Pokéidle. Se o Safari bloquear novas abas, abra os botões um por vez. Faça login na conta desejada dentro de cada aba — lembre que o login pode ficar compartilhado.
