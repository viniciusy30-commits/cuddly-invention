Quad Pokeidle

Atalho web para celular · quatro painéis

GRÁTIS · PWA
Importante: esta versão web é um atalho com até quatro painéis, não quatro perfis de navegador isolados. O Safari pode compartilhar o login entre eles, e o Pokéidle pode bloquear a abertura dentro dos painéis. Se isso acontecer, use Abrir fora. Não existe como contornar essas limitações apenas com uma página web.
O jogo é carregado diretamente de pokeidle.io. Esta página não pede nem armazena sua senha.
Para instalar no iPhone: abra no Safari → Compartilhar → Adicionar à Tela de Início.
